1. Crisp Sets vs Fuzzy Sets ↑ Unit III topics

Fuzzy logic was introduced by Lotfi A. Zadeh (1965) to handle concepts that are vague or imprecise — "tall", "hot", "fast", "young". In classical (crisp) logic a statement is either true (1) or false (0). In fuzzy logic, truth is a matter of degree anywhere in [0,1].

1.1 Crisp (classical) set

Let X be the universe of discourse (the set of all elements under consideration). A crisp set A⊆X is defined by its characteristic function:

χA​(x)={1,0,​x∈Ax∈/A​χA​:X→{0,1}

An element either belongs completely or does not belong at all — there is a sharp boundary.

1.2 Fuzzy set

A fuzzy set A~ in X is a set of ordered pairs

A~={(x, μA~​(x))​x∈X},μA~​:X→[0,1]
Terms
  • μA~​(x) — membership function (MF); gives the degree of membership (grade) of x in A~.
  • μ=1 → full member; μ=0 → not a member; 0<μ<1 → partial member.
  • The tilde "~" marks a fuzzy set; many books drop it and simply write A.

1.3 Notation (Zadeh's notation)

Discrete (finite) universe: A~={x1​μA~​(x1​)​+x2​μA~​(x2​)​+⋯}={i∑​xi​μA~​(xi​)​} Continuous universe: A~={∫X​xμA~​(x)​}
Important: In this notation the horizontal bar "/" is not division — it means "membership of element". The "+" is not addition — it means "collection / union of elements". The "∫" is not integration — it means a continuous collection of elements.
Example 1.1 — Crisp vs fuzzy "tall"
Universe: heights (cm) X={160,170,180,190}. Crisp "tall" = height ≥ 180. Fuzzy "tall" assigns grades.
Crisp: A={1600​+1700​+1801​+1901​}Fuzzy: A~={1600.2​+1700.5​+1800.8​+1901​}

A person of 179 cm is "not tall" in the crisp set (a sudden jump at 180), but is tall to degree ≈ 0.8 in the fuzzy set — much closer to human reasoning.

1.4 Crisp set vs Fuzzy set

Crisp setFuzzy set
Membership is 0 or 1Membership is any value in [0, 1]
Sharp boundaryGradual (vague) boundary
Based on bivalent (two-valued) logicBased on multi-valued (infinite-valued) logic
Law of excluded middle holds: A∪Aˉ=XDoes not hold: A~∪A~ˉ=X
Law of contradiction holds: A∩Aˉ=∅Does not hold: A~∩A~ˉ=∅
Example: {even numbers}Example: {numbers close to 10}
Fuzziness vs probability: Probability describes the likelihood of an uncertain event happening; fuzziness describes the degree to which an event/property is true. "μ(tall) = 0.8" does not mean an 80 % chance of being tall — it means the person is tall to degree 0.8.

max and min are special cases of t-conorms (s-norms) and t-norms. A t-norm T(a,b) (fuzzy AND) must be commutative, associative, monotonic and satisfy T(a,1)=a; examples: min, product ab, bounded max(0,a+b−1). A t-conorm S(a,b) (fuzzy OR) satisfies S(a,0)=a; examples: max, algebraic sum, bounded sum.

4. Properties of Fuzzy Sets ↑ Unit III topics

Fuzzy sets (with max, min, 1 − μ) obey almost all laws of crisp sets:

PropertyLaw
CommutativityA~∪B~=B~∪A~,A~∩B~=B~∩A~
AssociativityA~∪(B~∪C~)=(A~∪B~)∪C~,A~∩(B~∩C~)=(A~∩B~)∩C~
DistributivityA~∪(B~∩C~)=(A~∪B~)∩(A~∪C~),A~∩(B~∪C~)=(A~∩B~)∪(A~∩C~)
IdempotencyA~∪A~=A~,A~∩A~=A~
IdentityA~∪∅=A~,  A~∩X=A~,  A~∩∅=∅,  A~∪X=X
TransitivityIf A~⊆B~⊆C~ then A~⊆C~
Involution (double negation)A~ˉˉ=A~
AbsorptionA~∪(A~∩B~)=A~,A~∩(A~∪B~)=A~
De Morgan's lawsA~∪B~=A~ˉ∩B~ˉ,A~∩B~=A~ˉ∪B~ˉ
Excluded middle — FAILSA~∪A~ˉ=X
Contradiction — FAILSA~∩A~ˉ=∅

The failure of the last two laws is exactly what makes a set "fuzzy": an element can be partly in A~ and partly in its complement at the same time.

5. Fuzzy Relations ↑ Unit III topics

5.1 Crisp relation (background)

The Cartesian product of crisp sets X and Y is X×Y={(x,y)∣x∈X, y∈Y}. A crisp relation R is a subset of X×Y; its characteristic function χR​(x,y)=1 if (x,y)∈R, else 0. It can be written as a 0/1 matrix.

5.2 Fuzzy relation

A fuzzy relation R~ is a fuzzy set defined on the Cartesian product X×Y. Each ordered pair (x,y) has a degree of relationship μR~​(x,y)∈[0,1]:

R~={((x,y), μR~​(x,y))​(x,y)∈X×Y},μR~​:X×Y→[0,1]

For finite universes X={x1​,…,xm​}, Y={y1​,…,yn​}, a fuzzy relation is an m×n relation matrix:

R~=x1​⋮xm​​y1​μR​(x1​,y1​)⋮μR​(xm​,y1​)​y2​μR​(x1​,y2​)μR​(xm​,y2​)​⋯⋯⋯​yn​μR​(x1​,yn​)⋮μR​(xm​,yn​)​​

Example: "x is approximately equal to y", "city x is far from city y", "symptom x indicates disease y".

5.3 Fuzzy relation from Cartesian product

R~=A~×B~⇒μR~​(x,y)=min[μA~​(x), μB~​(y)]

6. Cardinality of Fuzzy Relations ↑ Unit III topics

6.1 Cardinality of crisp relations

If X has nX​ elements and Y has nY​ elements, the Cartesian product has

nX×Y​=nX​⋅nY​ elements,number of possible crisp relations=2nX​nY​

(each of the nX​nY​ pairs is either in or out of the relation). This number is the cardinality of the power set of X×Y.

6.2 Cardinality of fuzzy relations

In a fuzzy relation each pair can take any membership value in [0,1] — an infinite (uncountable) set of values. Therefore

cardinality of the set of all fuzzy relations on X×Y=∞

For a particular fuzzy relation we can compute its scalar cardinality just like a fuzzy set:

∣R~∣=x∈X∑​y∈Y∑​μR~​(x,y),∥R~∥=nX​nY​∣R~∣​

8. Properties of Fuzzy Relations ↑ Unit III topics

8.1 Algebraic properties

Fuzzy relations, being fuzzy sets on X×Y, obey: commutativity, associativity, distributivity, idempotency, identity (R~∪∅=R~, R~∩E=R~, R~∩∅=∅, R~∪E=E, where E is the whole relation with all entries 1 and ∅ the null relation with all entries 0), involution R~ˉˉ=R~, and De Morgan's laws. As with fuzzy sets, excluded middle and contradiction do not hold: R~∪R~ˉ=E, R~∩R~ˉ=∅.

8.2 Relational properties (relation on X×X)

PropertyConditionIn the matrix
ReflexiveμR​(x,x)=1  ∀xAll diagonal entries are 1
SymmetricμR​(x,y)=μR​(y,x)Matrix equals its transpose
Transitive (max-min)μR​(x,z)≥maxy​min[μR​(x,y), μR​(y,z)]R∘R⊆R
  • Fuzzy tolerance (proximity) relation: reflexive + symmetric.
  • Fuzzy equivalence (similarity) relation: reflexive + symmetric + transitive.
  • A tolerance relation R1​ can be converted into an equivalence relation by composing it with itself at most n−1 times (n = number of elements): R1n−1​=R1​∘R1​∘⋯∘R1​=R (the transitive closure).

9. Fuzzy Composition ↑ Unit III topics

Composition combines two relations that share a common set. If R~ is a relation on X×Y and S~ on Y×Z, their composition T~=R~∘S~ is a relation on X×Z — it answers "how strongly is x related to z through some y?"

9.1 Max-min composition

μT~​(x,z)=y∈Y⋁​[μR~​(x,y)∧μS~​(y,z)]=y∈Ymax​{min[μR~​(x,y), μS~​(y,z)]}

9.2 Max-product composition

μT~​(x,z)=y∈Ymax​[μR~​(x,y)⋅μS~​(y,z)]

How to compute: like matrix multiplication, but replace "×" by "min" (or product) and "+" by "max". Row i of R is combined with column j of S.

9.3 Properties of composition

  • Associative: (R~∘S~)∘M~=R~∘(S~∘M~)
  • Not commutative in general: R~∘S~=S~∘R~
  • Inverse: (R~∘S~)−1=S~−1∘R~−1
  • Monotonic: if S~⊆M~ then R~∘S~⊆R~∘M~
