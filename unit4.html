1. Fuzzy (Linguistic) Variables ↑ Unit IV topics

A linguistic variable is a variable whose values are words or sentences rather than numbers — e.g. temperature takes values "cold", "warm", "hot". Each word is represented by a fuzzy set. Zadeh defined it as a quintuple:

(x, T(x), U, G, M)
Terms
  • x — name of the variable (e.g. "temperature").
  • T(x) — term set: the set of linguistic values, e.g. {cold, warm, hot, very hot, not cold, …}.
  • U — universe of discourse (e.g. 0 °C to 50 °C).
  • G — syntactic rule (grammar) that generates the terms.
  • M — semantic rule that assigns to each term its meaning, i.e. a fuzzy set (membership function) on U.

A fuzzy variable (in the narrower sense) is a triple (X,U,R(X)), where X is the name, U the universe and R(X) a fuzzy subset of U giving the restriction on values of X (e.g. X = "old", U = ages 0–100).

2. Features of Membership Functions ↑ Unit IV topics

  • Core: region where μA​(x)=1.
  • Support: region where μA​(x)>0.
  • Boundary: region where 0<μA​(x)<1.
  • Normal: at least one element with μ=1; subnormal otherwise.
  • Convex: MF is monotonically increasing, then (possibly flat), then monotonically decreasing.
  • Crossover points: μA​(x)=0.5. Height: maximum membership value.
  • Prototypical element: element with the highest membership (e.g. peak of triangle).

Methods of assigning membership values: intuition (expert knowledge), inference (from geometry/rules), rank ordering (preferences/polls), angular fuzzy sets, neural networks, genetic algorithms, inductive reasoning (entropy minimisation).

μ(x)=max(min(b−ax−a​, 1, d−cd−x​), 0) a,d = feet; [b,c] = flat top (core). Triangular is a special case with b=c.

μ(x)=exp[−2σ2(x−c)2​] c = centre, σ = width. Smooth, differentiable everywhere, never exactly zero.

4. Fuzzy Rules ↑ Unit IV topics

Human knowledge is expressed as fuzzy IF–THEN rules:

IF x is A THEN y is B
  • "x is A" — antecedent (premise); A is a fuzzy set on X.
  • "y is B" — consequent (conclusion); B is a fuzzy set on Y (Mamdani) or a function (Sugeno).
  • Example: IF temperature is hot THEN fan speed is fast.

4.1 Types of rule statements

  • Assignment: x = large; "x is not very small".
  • Conditional: IF x is A THEN y is B.
  • Unconditional: "goto 5", "stop".
  • Compound rules use connectives:
    • AND (conjunction): μA1​∩A2​​=min(μA1​​(x1​), μA2​​(x2​)) — or product
    • OR (disjunction): μA1​∪A2​​=max(μA1​​(x1​), μA2​​(x2​))
    • NOT: 1−μA​(x)
  • Rule decomposition: "IF A THEN B ELSE C" = (IF A THEN B) OR (IF NOT A THEN C).

4.2 Fuzzy implication (meaning of a rule as a relation R)

ImplicationμR​(x,y)
Mamdani (min)min[μA​(x), μB​(y)]
Larsen (product)μA​(x)⋅μB​(y)
Zadeh (max-min)max{min[μA​(x),μB​(y)], 1−μA​(x)}
Łukasiewiczmin[1, 1−μA​(x)+μB​(y)]

4.3 Aggregation of rules

  • Disjunctive system (rules joined by OR/ELSE — usual case): μB​(y)=max[μB1​(y),μB2​(y),…,μBr​(y)].
  • Conjunctive system (all rules must hold — AND): μB​(y)=min[μB1​(y),…,μBr​(y)].

The two most important rule types — defined by the form of the consequent — are Mamdani and Takagi–Sugeno.

5. Mamdani Fuzzy Model ↑ Unit IV topics

Proposed by Ebrahim Mamdani (1975) to control a steam engine using rules from human operators. Both antecedent and consequent are fuzzy sets:

Ri​: IF x1​ is Ai1​ AND x2​ is Ai2​ THEN y is Bi​

5.1 Steps of Mamdani inference

  1. Fuzzify inputs: find μAi1​​(x1∗​), μAi2​​(x2∗​) for crisp inputs x1∗​,x2∗​.
  2. Firing strength of each rule (apply fuzzy operator): wi​=min[μAi1​​(x1∗​), μAi2​​(x2∗​)] for AND (max for OR).
  3. Implication: clip (min) the consequent at wi​: μBi′​​(y)=min[wi​, μBi​​(y)] (product implication scales it: wi​μBi​​(y)).
  4. Aggregation: combine all clipped consequents with max: μB′​(y)=maxi​μBi′​​(y).
  5. Defuzzification: convert μB′​ to a crisp output (usually centroid).

This is the "max-min" Mamdani method. Advantages: intuitive, well suited to human input, widely used. Disadvantage: defuzzification (centroid integral) is computationally heavy. A complete numerical is given in Inference.

6. Takagi–Sugeno (TSK) Fuzzy Model ↑ Unit IV topics

Proposed by Takagi, Sugeno and Kang (1985). Antecedents are fuzzy sets, but the consequent is a crisp function of the inputs:

Ri​: IF x is Ai​ AND y is Bi​ THEN zi​=fi​(x,y) First-order Sugeno: zi​=pi​x+qi​y+ri​    Zero-order Sugeno: zi​=ki​ (constant)
Crisp output (weighted average — no separate defuzzification needed): z∗=∑i=1N​wi​∑i=1N​wi​zi​​,wi​=firing strength of rule i
Terms
  • pi​,qi​,ri​ — consequent parameters (found by expert or by least squares / ANFIS training).
  • wi​ — firing strength (min or product of antecedent memberships).
  • Normalised strength wˉi​=wi​/∑wj​ gives z∗=∑wˉi​zi​.

Advantages: computationally efficient, works well with linear/optimisation/adaptive techniques (ANFIS), guarantees continuity of output surface, good for mathematical analysis. Disadvantage: consequents are less intuitive for humans.

7. Fuzzy Inference System (FIS) ↑ Unit IV topics

A fuzzy inference system (fuzzy rule-based system / fuzzy controller) maps crisp inputs to crisp outputs using fuzzy set theory, IF-THEN rules and fuzzy reasoning.

BlockFunction
Fuzzification interfaceConverts crisp inputs into degrees of membership of the linguistic terms.
DatabaseDefines the membership functions of all fuzzy sets used in the rules.
Rule baseContains the set of fuzzy IF-THEN rules.
Knowledge baseDatabase + rule base together.
Inference engine (decision-making unit)Applies the rules to the fuzzified inputs (firing strength, implication, aggregation).
Defuzzification interfaceConverts the aggregated fuzzy output into a crisp value.

Working in five steps: (1) fuzzify inputs → (2) apply fuzzy operator (AND/OR) in antecedents → (3) apply implication to each rule → (4) aggregate all rule outputs → (5) defuzzify. Applications: washing machines, air-conditioners, auto-focus cameras, anti-lock braking, cement kilns, metro train control (Sendai), rice cookers.

8. Fuzzification ↑ Unit IV topics

Fuzzification is the process of converting a crisp quantity into a fuzzy quantity, i.e. finding the degree to which a crisp input belongs to each linguistic term. Measurements contain imprecision (noise, sensor error), so treating them as fuzzy is natural.

  • Singleton fuzzification: crisp input x∗ is represented by a fuzzy singleton (μ = 1 at x∗ only) — most common; then the membership in term A is simply μA​(x∗).
  • Non-singleton (e.g. Gaussian/triangular) fuzzification: input represented by a fuzzy number centred at x∗ to model noise.

9. Rule Base & Database ↑ Unit IV topics

The rule base stores all IF-THEN rules; the database stores the definitions (MFs) of all linguistic terms. Rules are obtained from expert knowledge, operator experience, fuzzy models of the process, or learning (neural/GA). For two inputs with m and n terms, a complete rule base has at most m×n rules, often shown as a Fuzzy Associative Memory (FAM) table.

Desirable properties: completeness (every input combination fires at least one rule), consistency (no contradictory rules with same antecedent and different consequents), continuity (neighbouring rules have neighbouring consequents), and minimal redundancy.

Rule base for the fan example (used in Section 10)

RuleStatement
R1IF Temperature is Warm AND Humidity is Medium THEN Speed is Medium
R2IF Temperature is Hot OR Humidity is High THEN Speed is Fast
R3IF Temperature is Cold THEN Speed is Slow

Output Speed (0–100 %): Slow = trimf(0, 25, 50), Medium = trimf(25, 50, 75), Fast = trimf(50, 75, 100).

11. Defuzzification ↑ Unit IV topics

11.2 Criteria for choosing a method

Continuity (small input change → small output change), disambiguity (unique value), plausibility (lies near the middle of the support with high membership), computational simplicity, and weighting of rule outputs. Centroid satisfies most criteria; weighted average and COS are preferred when speed matters.
