1. The Biological Neural Network ↑ Unit I topics

The human brain is the inspiration for artificial neural networks. It contains about \(10^{11}\) (≈ 86 billion) nerve cells called neurons. Each neuron is connected to roughly \(10^{3}\)–\(10^{4}\) other neurons, giving about \(10^{14}\)–\(10^{15}\) connections (synapses). Even though a single neuron is slow (switching time ≈ \(10^{-3}\) s, compared with ≈ \(10^{-9}\) s for a silicon gate), the brain is extremely powerful because of this massive parallelism.

1.2 How a biological neuron works

  1. Resting state: the inside of the neuron is negative with respect to the outside; the resting membrane potential is about \(-70\ \text{mV}\), maintained by the Na⁺/K⁺ pump.
  2. Receiving inputs: neurotransmitters released at synapses change the potential of the dendrites. Excitatory inputs raise the potential; inhibitory inputs lower it.
  3. Integration: the soma sums all these changes (spatial and temporal summation).
  4. Firing: if the potential at the axon hillock reaches the threshold (≈ \(-55\ \text{mV}\)), an action potential (spike ≈ \(+30\ \text{mV}\)) is generated. This is an all-or-none event — the neuron either fires fully or not at all. This is the basis of the binary threshold idea used in the McCulloch–Pitts model.
  5. Refractory period: after firing, the neuron cannot fire again for about 1–2 ms.
  6. Transmission: the spike travels along the axon and releases neurotransmitters at the axon terminals, affecting the next neurons.
  7. Learning: synaptic strengths change with experience (synaptic plasticity) — this is what Hebb described and what the "weights" model in ANN.
Key idea: A neuron (i) collects weighted inputs, (ii) sums them, (iii) compares the sum with a threshold, and (iv) fires an output. An artificial neuron copies exactly these four steps mathematically.

2. Artificial Neural Networks ↑ Unit I topics

Definition (Haykin): "A neural network is a massively parallel distributed processor made up of simple processing units (neurons), which has a natural propensity for storing experiential knowledge and making it available for use." It resembles the brain in two respects:

  1. Knowledge is acquired by the network from its environment through a learning process.
  2. Inter-neuron connection strengths, known as synaptic weights, are used to store the acquired knowledge.

In simple words, an ANN is an information-processing system made of many interconnected nodes/units/neurons. Each connection has a weight; each neuron computes a weighted sum of its inputs and passes it through an activation function to produce an output.

2.1 Characteristics of ANN

  • Massive parallelism – many neurons compute simultaneously.
  • Distributed representation – knowledge is spread over all weights, not stored at one address.
  • Learning ability – weights are adjusted from examples; no explicit programming of rules.
  • Generalisation – gives reasonable outputs for inputs not seen during training.
  • Fault tolerance / graceful degradation – damage to a few neurons/weights only slightly reduces performance.
  • Non-linearity – non-linear activation functions let the network model non-linear relationships.
  • Adaptivity – can be retrained when the environment changes.
  • Input–output mapping – learns a mapping \(\mathbf{x} \mapsto \mathbf{y}\) from sample pairs.

3.1 Mathematical model of an artificial neuron

The neuron performs two operations:

(a) Net input (weighted sum): \[ y_{in} \;=\; b + x_1 w_1 + x_2 w_2 + \cdots + x_n w_n \;=\; b + \sum_{i=1}^{n} x_i\, w_i \] (b) Output: \[ y \;=\; f\!\left(y_{in}\right) \] Vector form: with \(\mathbf{x} = [x_1, x_2, \dots, x_n]\) and \(\mathbf{w} = [w_1, w_2, \dots, w_n]^{T}\): \[ y_{in} = b + \mathbf{x}\,\mathbf{w} = b + \mathbf{w}^{T}\mathbf{x}^{T} \] Bias as a weight: treat the bias as weight \(w_0 = b\) on a constant input \(x_0 = 1\): \[ y_{in} = \sum_{i=0}^{n} x_i\, w_i ,\qquad x_0 = 1 \]
Explanation of each term
  • \(x_i\) — the \(i^{th}\) input signal (activation of input unit \(X_i\)); \(n\) = number of inputs.
  • \(w_i\) — weight of the connection from input \(i\) to the neuron; it multiplies the input. Large positive = strong excitatory, negative = inhibitory, zero = no connection.
  • \(b\) — bias; a constant added to the net input that shifts the decision boundary away from the origin.
  • \(\sum\) — summation symbol ("add up for \(i = 1\) to \(n\)").
  • \(y_{in}\) — net input (also called induced local field or activation potential).
  • \(f(\cdot)\) — activation (transfer) function; maps \(y_{in}\) to the output.
  • \(y\) — output of the neuron.

3.2 Multiple output neurons (matrix form)

For \(n\) inputs and \(m\) output neurons, weights form an \(n \times m\) weight matrix \(W = [w_{ij}]\), where \(w_{ij}\) is the weight from input unit \(X_i\) to output unit \(Y_j\):

\[ W = \begin{bmatrix} w_{11} & w_{12} & \cdots & w_{1m}\\ w_{21} & w_{22} & \cdots & w_{2m}\\ \vdots & \vdots & \ddots & \vdots\\ w_{n1} & w_{n2} & \cdots & w_{nm}\end{bmatrix},\qquad y_{in,j} = b_j + \sum_{i=1}^{n} x_i\, w_{ij},\quad j = 1,2,\dots,m \] In compact form: \( \mathbf{y}_{in} = \mathbf{b} + \mathbf{x}\,W \) and \( y_j = f(y_{in,j}) \).

4. ANN Terminologies ↑ Unit I topics

4.1 Weights

Weights are the information that the network uses to solve a problem. Each link carries a weight \(w_{ij}\) (from neuron \(i\) to neuron \(j\)). Learning = finding good weights. The set of all weights is the weight matrix \(W\) (also called the connection matrix).

4.2 Bias

Bias \(b\) is a weight on a connection whose input is always 1. It is like the intercept \(c\) in the straight-line equation \(y = mx + c\).

  • Positive bias increases the net input (neuron fires more easily).
  • Negative bias decreases the net input (neuron fires less easily).

Without bias, the decision boundary \(\sum x_i w_i = 0\) must pass through the origin; with bias it can be shifted anywhere.

4.3 Threshold (\(\theta\))

Threshold is a set value against which the net input is compared to decide the output:

\[ y = f(y_{in}) = \begin{cases} 1, & y_{in} \ge \theta \\ -1, & y_{in} \lt \theta \end{cases} \]

Relation between bias and threshold: \( \sum x_i w_i \ge \theta \;\Longleftrightarrow\; -\theta + \sum x_i w_i \ge 0 \). So a threshold \(\theta\) is equivalent to a bias \(b = -\theta\) with the threshold then set to 0.

4.4 Learning rate (\(\alpha\) or \(\eta\))

Controls the size of each weight adjustment: \( \Delta w = \alpha \times (\text{correction term}) \). Usually \(0 \lt \alpha \le 1\). Too small → slow learning; too large → oscillation / divergence.

4.5 Momentum factor (\(\mu\))

Adds a fraction of the previous weight change to the current change to speed up convergence and avoid oscillation (used in back-propagation):

\[ \Delta w(t+1) = \alpha\,\delta\,x \;+\; \mu\,\Delta w(t), \qquad 0 \le \mu \lt 1 \]

4.6 Vigilance parameter (\(\rho\))

Used in Adaptive Resonance Theory (ART) networks; controls how similar an input must be to a stored cluster to be put in that cluster. Range typically \(0.7 \le \rho \le 1\). High \(\rho\) → many fine clusters; low \(\rho\) → few coarse clusters.

5. Architecture (Network Topology) ↑ Unit I topics

The architecture is the arrangement of neurons into layers and the pattern of connections within and between layers.

  • Layer — a group of neurons at the same level. Input layer only passes on the inputs (no computation, so it is usually not counted). Output layer produces the final result. Hidden layer(s) lie in between and are not directly visible from outside.
  • Feedforward — signals flow only in one direction: input → output, no loops.
  • Feedback (recurrent) — outputs are fed back as inputs to the same or earlier layers (loops exist).
  • Lateral connections — connections between neurons of the same layer (e.g. competitive / "winner-take-all" nets).
  • Fully connected — every neuron of one layer is connected to every neuron of the next layer.

6. Setting of Weights (Learning / Training) ↑ Unit I topics

Learning (training) is the process by which the free parameters (weights and biases) of a network are adapted by stimulation from the environment. The general weight update is:

\[ w_{ij}(\text{new}) = w_{ij}(\text{old}) + \Delta w_{ij} \] where \(\Delta w_{ij}\) (read "delta w") is the weight change computed by the learning rule.

6.1 Supervised learning

Learning with a teacher. Each input \(\mathbf{x}\) is presented with the desired target \(\mathbf{t}\). The network computes \(\mathbf{y}\), the error \(\mathbf{e} = \mathbf{t} - \mathbf{y}\) is found and used to adjust weights until the error is acceptable.

Examples: Perceptron rule, Delta rule, Back-propagation, LVQ, RBFN (output layer).

6.2 Unsupervised learning

Learning without a teacher. No target is given. The network discovers patterns, regularities, or clusters in the inputs by itself (self-organisation). Similar inputs activate the same output (cluster) unit.

Examples: Kohonen SOM, ART, competitive learning, Hebbian learning (unsupervised form).

6.3 Reinforcement learning

Like supervised learning, but instead of the exact target only a critic signal (reward/penalty, "good/bad") is given. The network adjusts weights to maximise reward.

6.4 Fixed-weight networks

Weights are not learnt iteratively; they are set once (designed or computed directly) according to the problem. Examples: McCulloch–Pitts neuron, Hopfield net (weights computed from stored patterns in one shot), MAXNET.

6.5 Practical aspects of setting weights

  • Initialisation: zero (Hebb, Perceptron), small random values in \([-0.5, 0.5]\) (BPN), or Nguyen–Widrow initialisation.
  • Incremental (on-line / pattern) mode: update after every training pattern.
  • Batch mode: accumulate changes over the whole epoch and update once.
  • Stopping condition: no weight change during an epoch, error below tolerance, or maximum epochs reached.

7. Activation Functions ↑ Unit I topics

An activation (transfer / squashing) function \(f\) converts the net input \(y_{in}\) into the output \(y = f(y_{in})\). Non-linear activation functions are essential in multilayer networks — with only linear functions, any number of layers collapses into a single linear layer. Functions used with gradient-based learning (Delta rule, BPN) must be differentiable.

In the formulas below \(x\) denotes the net input \(y_{in}\), \(\theta\) is the threshold, and \(\lambda \gt 0\) is the steepness parameter (larger \(\lambda\) → steeper curve).

7.1 Identity (linear) function

\[ f(x) = x \quad \text{for all } x, \qquad f'(x) = 1 \]

Output equals net input. Used in input units and in the output layer of ADALINE / RBFN / regression networks.

7.2 Binary step function (with threshold \(\theta\))

\[ f(x) = \begin{cases} 1, & x \ge \theta \\ 0, & x \lt \theta \end{cases} \]

Also called the Heaviside or threshold function. Output is binary (0/1). Used in McCulloch–Pitts neurons and single-layer nets. Not differentiable at \(x = \theta\).

7.3 Bipolar step function

\[ f(x) = \begin{cases} +1, & x \ge \theta \\ -1, & x \lt \theta \end{cases} \]

Perceptron's three-level variant (with an undecided band of width \(2\theta\)):

\[ f(y_{in}) = \begin{cases} 1, & y_{in} \gt \theta \\ 0, & -\theta \le y_{in} \le \theta \\ -1, & y_{in} \lt -\theta \end{cases} \]

7.4 Binary sigmoid (logistic / unipolar sigmoid)

\[ f(x) = \frac{1}{1 + e^{-\lambda x}}, \qquad \text{range } (0,\,1) \] Derivative: \[ f'(x) = \frac{\lambda\, e^{-\lambda x}}{\left(1+e^{-\lambda x}\right)^2} = \lambda\, f(x)\,\bigl[1 - f(x)\bigr] \]

Derivation of derivative: Let \(f = (1+e^{-\lambda x})^{-1}\). Then \(f' = -(1+e^{-\lambda x})^{-2}\cdot(-\lambda e^{-\lambda x}) = \lambda \cdot \dfrac{1}{1+e^{-\lambda x}}\cdot\dfrac{e^{-\lambda x}}{1+e^{-\lambda x}} = \lambda f (1-f)\), because \(\dfrac{e^{-\lambda x}}{1+e^{-\lambda x}} = 1 - f\). The derivative is written in terms of \(f\) itself, which makes back-propagation computationally cheap. Maximum slope is at \(x = 0\): \(f(0) = 0.5,\ f'(0) = \lambda/4\).

7.5 Bipolar sigmoid

\[ b(x) = \frac{2}{1+e^{-\lambda x}} - 1 = \frac{1 - e^{-\lambda x}}{1 + e^{-\lambda x}}, \qquad \text{range } (-1,\,1) \] Derivative: \[ b'(x) = \frac{\lambda}{2}\,\bigl[1 + b(x)\bigr]\bigl[1 - b(x)\bigr] \]

7.6 Hyperbolic tangent

\[ h(x) = \tanh(x) = \frac{e^{x} - e^{-x}}{e^{x} + e^{-x}} = \frac{1 - e^{-2x}}{1 + e^{-2x}}, \qquad h'(x) = 1 - h^2(x) = \bigl[1+h(x)\bigr]\bigl[1-h(x)\bigr] \] Relation: \( b(x) = \tanh\!\left(\dfrac{\lambda x}{2}\right) \) — the bipolar sigmoid is a scaled tanh.

7.7 Ramp function

\[ f(x) = \begin{cases} 1, & x \gt 1 \\ x, & 0 \le x \le 1 \\ 0, & x \lt 0 \end{cases} \]

7.8 ReLU (Rectified Linear Unit) — modern networks

\[ f(x) = \max(0,\,x), \qquad f'(x) = \begin{cases}1, & x \gt 0\\ 0, & x \lt 0\end{cases} \]

8. McCulloch–Pitts Neuron Model ↑ Unit I topics

Proposed by Warren McCulloch and Walter Pitts (1943). It is the first computational model of a neuron, usually called the M-P neuron or Threshold Logic Unit.

8.1 Features

  • Inputs and output are binary (0 or 1).
  • Connections are either excitatory with weight \(w \gt 0\), or inhibitory with weight \(-p\) (\(p \gt 0\)). All excitatory connections into a particular neuron have the same weight.
  • The neuron fires (output 1) if the net input is at least the threshold \(\theta\).
  • Weights and threshold are fixed — there is no learning; they are set by analysis.
  • Absolute inhibition: threshold is chosen so that any non-zero inhibitory input prevents firing.
  • A signal takes one time step (one synaptic delay) to pass over a connection.

8.2 Mathematical model

\[ y_{in} = \sum_{i=1}^{n} x_i\,w_i \;\;(\text{excitatory}) \;+\; \sum_{k=1}^{m} x_{n+k}(-p) \;\;(\text{inhibitory}) \] \[ y = f(y_{in}) = \begin{cases} 1, & y_{in} \ge \theta \\ 0, & y_{in} \lt \theta \end{cases} \] Threshold condition for absolute inhibition: \[ \theta \gt n\,w - p \] Condition for firing when \(k\) or more excitatory inputs are active (no inhibition): \[ k\,w \ge \theta \gt (k-1)\,w \]
Terms
  • \(n\) — number of excitatory inputs, \(w\) — weight of each excitatory input.
  • \(p\) — magnitude of the inhibitory weight (the weight is \(-p\)).
  • \(\theta\) — threshold; chosen by the designer.
  • \(k\) — minimum number of active excitatory inputs needed to fire.

Procedure to design an M-P network: (1) Write the truth table. (2) Assume weights (e.g. all 1). (3) Compute \(y_{in}\) for every input combination. (4) Pick \(\theta\) so that \(y_{in} \ge \theta\) exactly when the target is 1. (5) If no such \(\theta\) exists, change the weights (make some inhibitory) or add hidden neurons.

9. Hebbian Learning Rule ↑ Unit I topics

Donald Hebb (1949), The Organization of Behavior: "When an axon of cell A is near enough to excite cell B and repeatedly or persistently takes part in firing it, some growth process or metabolic change takes place in one or both cells such that A's efficiency, as one of the cells firing B, is increased."

In short: if two connected neurons are active simultaneously, the strength of the connection between them increases. Extended form: if they are activated in opposite sense (one +1, other −1), the weight decreases. This is why bipolar data is preferred.

9.1 The rule

\[ w_i(\text{new}) = w_i(\text{old}) + x_i\,y, \qquad b(\text{new}) = b(\text{old}) + y \] \[ \Delta w_i = x_i\, y \qquad(\text{or with learning rate: } \Delta w_i = \alpha\, x_i\, y) \] Vector / matrix (outer-product) form: \[ W(\text{new}) = W(\text{old}) + \mathbf{x}^{T}\mathbf{y}, \qquad W = \sum_{p=1}^{P} \mathbf{s}^{T}(p)\,\mathbf{t}(p) \]
Terms
  • \(x_i\) — activation of the pre-synaptic (input) unit.
  • \(y\) — activation of the post-synaptic (output) unit. In the supervised Hebb net, \(y\) is set to the target \(t\).
  • \(\Delta w_i\) — change in weight = product of the two activities (a correlation).
  • \(\mathbf{s}^{T}(p)\mathbf{t}(p)\) — outer product of the \(p^{th}\) input (column) and target (row).

9.2 Hebb net training algorithm

  1. Initialise all weights and bias to zero: \(w_i = 0\ (i = 1,\dots,n),\ b = 0\).
  2. For each training pair \(s : t\), do Steps 2–4.
  3. Set input activations: \(x_i = s_i\).
  4. Set output activation equal to target: \(y = t\).
  5. Update: \(w_i(\text{new}) = w_i(\text{old}) + x_i\,y\), \(\;b(\text{new}) = b(\text{old}) + y\).

Training is done in one epoch only (one pass over the data). Hebb rule is used in Hebb nets, Hopfield nets, BAM and associative memories.

10. Perceptron Learning Rule ↑ Unit I topics

Introduced by Frank Rosenblatt (1958). The original perceptron had three kinds of units: Sensory units (S) → Association units (A) (fixed weights) → Response unit (R) (adjustable weights). Only the weights from A to R are learnt. It is a supervised, error-correcting rule: weights change only when the output is wrong.

10.1 Activation

\[ y = f(y_{in}) = \begin{cases} 1, & y_{in} \gt \theta \\ 0, & -\theta \le y_{in} \le \theta \\ -1, & y_{in} \lt -\theta \end{cases} \qquad y_{in} = b + \sum_{i=1}^{n} x_i w_i \]

10.2 The rule

\[ \text{If } y \ne t:\quad w_i(\text{new}) = w_i(\text{old}) + \alpha\, t\, x_i, \qquad b(\text{new}) = b(\text{old}) + \alpha\, t \] \[ \text{If } y = t:\quad w_i(\text{new}) = w_i(\text{old}),\qquad b(\text{new}) = b(\text{old}) \] Equivalent error form (for binary output): \( \Delta w_i = \alpha\,(t - y)\,x_i \)
Terms
  • \(t\) — target (+1 or −1); \(y\) — actual output; \(\alpha\) — learning rate (\(0 \lt \alpha \le 1\)).
  • \(\theta\) — fixed non-negative threshold that creates an "undecided" band \([-\theta, \theta]\); outputs 0 in this band count as errors.

Geometric meaning: if the output should be +1 but is not, the weight vector is moved towards \(\mathbf{x}\) (\(\mathbf{w} + \alpha\mathbf{x}\)); if it should be −1, it is moved away from \(\mathbf{x}\) (\(\mathbf{w} - \alpha\mathbf{x}\)). This rotates the decision line until all points fall on the correct side.

10.3 Perceptron convergence theorem

If the training patterns are linearly separable, the perceptron learning rule is guaranteed to find a weight vector that classifies all patterns correctly in a finite number of steps. If the patterns are not linearly separable (e.g. XOR), the weights keep oscillating forever.

10.4 Training algorithm

  1. Initialise weights and bias (zero or small random). Set \(\alpha\) (\(0 \lt \alpha \le 1\)) and \(\theta\).
  2. While the stopping condition is false, do Steps 2–6.
  3. For each training pair \(s : t\), do Steps 3–5.
  4. Set input activations \(x_i = s_i\).
  5. Compute \(y_{in} = b + \sum x_i w_i\) and \(y = f(y_{in})\).
  6. If \(y \ne t\): \(w_i \leftarrow w_i + \alpha t x_i,\ b \leftarrow b + \alpha t\); else no change.
  7. Stop if no weight changed during the epoch; otherwise continue.

11. Delta Learning Rule (Widrow–Hoff / LMS Rule) ↑ Unit I topics

Developed by Bernard Widrow and Marcian Hoff (1960) for ADALINE (ADAptive LInear NEuron). Also called the Least Mean Square (LMS) rule. It adjusts the weights to minimise the squared error between the target and the net input using gradient descent.

11.1 Derivation

For one output unit and one training pattern, define the squared error:

\[ E = \frac{1}{2}\left(t - y_{in}\right)^2, \qquad y_{in} = b + \sum_{i=1}^{n} x_i w_i \]

Gradient descent moves each weight in the direction of the negative gradient:

\[ \frac{\partial E}{\partial w_i} = \frac{\partial E}{\partial y_{in}}\cdot\frac{\partial y_{in}}{\partial w_i} = -(t - y_{in})\cdot x_i \] \[ \Delta w_i = -\alpha\,\frac{\partial E}{\partial w_i} = \alpha\,(t - y_{in})\,x_i \] \[ \boxed{\,w_i(\text{new}) = w_i(\text{old}) + \alpha\,(t - y_{in})\,x_i,\qquad b(\text{new}) = b(\text{old}) + \alpha\,(t - y_{in})\,} \]
Terms
  • \(E\) — squared error (the ½ is included only to cancel the 2 on differentiation).
  • \(\partial E / \partial w_i\) — partial derivative (gradient) of error w.r.t. weight \(w_i\): how much \(E\) changes when \(w_i\) changes slightly.
  • \(t - y_{in}\) — the error "delta" (δ) — hence the name Delta rule.
  • \(\alpha\) — learning rate; for ADALINE a common guideline is \(0.1 \le n\alpha \le 1.0\) (\(n\) = number of inputs).
  • Over all \(P\) patterns the total error is \(E = \sum_{p=1}^{P}(t_p - y_{in,p})^2\); the rule reaches the least-squares solution.

11.2 Generalised delta rule (non-linear, differentiable activation)

If the output is \(y = f(y_{in})\) with differentiable \(f\) (e.g. sigmoid), minimising \(E = \frac12 (t - y)^2\) gives:

\[ \frac{\partial E}{\partial w_i} = -(t - y)\,f'(y_{in})\,x_i \;\;\Rightarrow\;\; \Delta w_i = \alpha\,(t - y)\,f'(y_{in})\,x_i = \alpha\,\delta\,x_i, \qquad \delta = (t-y)\,f'(y_{in}) \] For binary sigmoid: \(f'(y_{in}) = y(1-y)\). This is the basis of back-propagation.

11.4 ADALINE training algorithm

  1. Initialise weights to small random values; set learning rate \(\alpha\).
  2. While stopping condition is false, do Steps 2–6.
  3. For each bipolar training pair \(s : t\), do Steps 3–5.
  4. Set activations \(x_i = s_i\).
  5. Compute net input \(y_{in} = b + \sum x_i w_i\).
  6. Update \(w_i \leftarrow w_i + \alpha (t - y_{in}) x_i\), \(b \leftarrow b + \alpha(t - y_{in})\).
  7. If the largest weight change in the epoch is smaller than a tolerance (or \(E\) is small), stop.

After training, the output is obtained with the bipolar step: \(y = 1\) if \(y_{in} \ge 0\), else \(-1\).

1. Single Layer Perceptron ↑ Unit II topics

A single layer perceptron (SLP) is the simplest feedforward network: an input layer connected directly to one layer of output (perceptron) neurons through adjustable weights. It is trained using the perceptron learning rule and is used for classification of linearly separable patterns.

1.1 Architecture

  • Input units \(X_1, \dots, X_n\) — pass the input signals (the "sensory" units); they do no computation.
  • Bias unit — has a constant activation of 1; its weight is the bias \(b\).
  • Output unit(s) \(Y_1, \dots, Y_m\) — each computes \(y_{in,j} = b_j + \sum_i x_i w_{ij}\) and applies the 3-level activation.
  • Only one layer of adjustable weights (hence "single layer"). The weights from input to output are the ones learnt.
\[ y_{in,j} = b_j + \sum_{i=1}^{n} x_i\,w_{ij}, \qquad y_j = f(y_{in,j}) = \begin{cases} 1, & y_{in,j} \gt \theta \\ 0, & -\theta \le y_{in,j} \le \theta \\ -1, & y_{in,j} \lt -\theta \end{cases} \]

1.2 Training algorithm (multiple output classes)

  1. Initialise weights \(w_{ij}\) and biases \(b_j\) (to 0 or small random values). Set learning rate \(\alpha\) (\(0 \lt \alpha \le 1\)) and threshold \(\theta\).
  2. While the stopping condition is false, perform Steps 2–6.
  3. For each training pair \(s : t\), perform Steps 3–5.
  4. Set input activations: \(x_i = s_i,\ i = 1,\dots,n\).
  5. For each output unit \(j = 1,\dots,m\): compute \(y_{in,j} = b_j + \sum_{i=1}^{n} x_i w_{ij}\) and \(y_j = f(y_{in,j})\).
  6. Weight update — for each \(j\) and \(i\): \[ \text{if } t_j \ne y_j:\quad w_{ij}(\text{new}) = w_{ij}(\text{old}) + \alpha\,t_j\,x_i,\quad b_j(\text{new}) = b_j(\text{old}) + \alpha\,t_j \] \[ \text{if } t_j = y_j:\quad w_{ij}(\text{new}) = w_{ij}(\text{old}),\quad b_j(\text{new}) = b_j(\text{old}) \]
  7. Test stopping condition: if no weight changed during the whole epoch, stop; else go to Step 1.
Flow in words: Present input → compute net input → apply activation → compare with target → if wrong, add \(\alpha t \mathbf{x}\) to weights → repeat for all patterns → repeat epochs until an entire epoch passes with no error.

1.3 Application (testing) procedure

After training, the network is used to classify new inputs. No weights change during application.

  1. Set the weights and biases to the final values obtained from training.
  2. For each input vector \(\mathbf{x}\) to be classified, perform Steps 2–3.
  3. Set activations of the input units: \(x_i\).
  4. Compute the net input \(y_{in,j} = b_j + \sum_i x_i w_{ij}\) and apply the activation to obtain \(y_j = f(y_{in,j})\). Output \(+1\) → pattern belongs to class \(j\); \(-1\) → does not; \(0\) → undecided.

1.4 Linear separability and the XOR problem

A single perceptron (one output) implements the decision boundary \(b + w_1x_1 + w_2x_2 = 0\) — a straight line. It can only separate classes that lie on opposite sides of a line (hyper-plane in \(n\) dimensions). Such problems are called linearly separable (AND, OR, NAND, NOR).

XOR is not linearly separable. Proof (binary inputs, output 1 if \(y_{in} \gt 0\)):

\[ (0,0) \to 0:\ b \le 0 \qquad (0,1) \to 1:\ w_2 + b \gt 0 \qquad (1,0) \to 1:\ w_1 + b \gt 0 \qquad (1,1) \to 0:\ w_1 + w_2 + b \le 0 \] Adding the 2nd and 3rd inequalities: \( w_1 + w_2 + 2b \gt 0 \Rightarrow w_1 + w_2 + b \gt -b \ge 0 \) (since \(b \le 0\)), which contradicts the 4th inequality. Hence no \(w_1, w_2, b\) exist. ∎

This limitation (Minsky & Papert, 1969) is overcome by multilayer networks (e.g. BPN, RBFN, or the two-layer M-P XOR network).

2. Feedback Networks & Associative Memory ↑ Unit II topics

In feedback (recurrent) networks the outputs are fed back as inputs, so the network is a dynamical system: after an input is applied, the network iterates (updates its state again and again) until it settles in a stable state (equilibrium). Stored patterns are these stable states (attractors).

They are mainly used as associative memories — "content-addressable memories" that recall a complete stored pattern from a partial or noisy version (like remembering a whole song from hearing a few notes).

2.3 Weight determination (outer-product / Hebb rule)

\[ W = \sum_{p=1}^{P} \mathbf{s}^{T}(p)\,\mathbf{t}(p) \qquad\text{i.e.}\qquad w_{ij} = \sum_{p=1}^{P} s_i(p)\,t_j(p) \]

Here \(\mathbf{s}^{T}(p)\) is the \(p^{th}\) input as a column vector and \(\mathbf{t}(p)\) the target as a row vector, so each term is an outer product (a matrix).

3. Hopfield Net ↑ Unit II topics

Proposed by John J. Hopfield (1982). It is a single-layer, fully interconnected, recurrent, auto-associative network. Two versions: Discrete Hopfield (binary/bipolar units, 1982) and Continuous Hopfield (continuous-valued units, 1984).

3.1 Architecture of the discrete Hopfield net

  • \(n\) processing units \(Y_1, \dots, Y_n\); each also receives an external input \(x_i\).
  • Symmetric weights: \(w_{ij} = w_{ji}\).
  • No self-connections: \(w_{ii} = 0\).
  • Asynchronous update: only one unit updates its activation at a time (in random or fixed order), and each unit continues to receive the external input. Asynchronous update + symmetric weights guarantee convergence (the energy never increases).

3.2 Training (storage) algorithm — weights by Hebb rule

Binary patterns \(s(p) \in \{0,1\}^n\): \[ w_{ij} = \sum_{p=1}^{P} \bigl[2s_i(p) - 1\bigr]\bigl[2s_j(p) - 1\bigr], \quad i \ne j;\qquad w_{ii} = 0 \] Bipolar patterns \(s(p) \in \{-1,1\}^n\): \[ w_{ij} = \sum_{p=1}^{P} s_i(p)\,s_j(p), \quad i \ne j;\qquad w_{ii} = 0 \] Matrix form: \( W = \sum_{p=1}^{P} \mathbf{s}^{T}(p)\,\mathbf{s}(p) \;-\; P\,I \) (subtracting \(P I\) makes the diagonal zero).
Terms
  • \(P\) — number of stored patterns; \(n\) — number of units (length of each pattern).
  • \(2s - 1\) — converts binary \(\{0,1\}\) to bipolar \(\{-1,1\}\).
  • \(I\) — identity matrix.

3.3 Testing (recall) algorithm

  1. Initialise weights using the storage rule (Hebb).
  2. While activations have not converged, do Steps 2–6.
  3. For each input vector \(\mathbf{x}\), do Steps 3–6.
  4. Set the initial activations of the net equal to the external input: \(y_i = x_i,\ i = 1,\dots,n\).
  5. Perform Steps 5–6 for each unit \(Y_i\) (units taken in random/fixed order, one at a time).
  6. Compute net input: \( y_{in,i} = x_i + \sum_{j} y_j\,w_{ji} \)
  7. Apply activation and broadcast \(y_i\) to all other units: \[ y_i = \begin{cases} 1, & y_{in,i} \gt \theta_i \\ y_i \ (\text{unchanged}), & y_{in,i} = \theta_i \\ 0, & y_{in,i} \lt \theta_i \end{cases} \] (for bipolar nets use −1 instead of 0). Usually \(\theta_i = 0\).
  8. Test for convergence: if no activation changed in a full sweep, stop.

3.4 Energy (Lyapunov) function

\[ E = -\frac{1}{2}\sum_{i=1}^{n}\sum_{\substack{j=1\\ j\ne i}}^{n} y_i\,y_j\,w_{ij} \;-\; \sum_{i=1}^{n} x_i\,y_i \;+\; \sum_{i=1}^{n} \theta_i\,y_i \] Change in energy when unit \(Y_i\) changes by \(\Delta y_i\): \[ \Delta E = -\Bigl[\sum_{j} y_j\,w_{ij} + x_i - \theta_i\Bigr]\Delta y_i \]

Why the net converges: the bracket is \(y_{in,i} - \theta_i\). If it is positive, \(y_i\) can only change from 0→1 (\(\Delta y_i \gt 0\)); if negative, only 1→0 (\(\Delta y_i \lt 0\)). In both cases \(\Delta E \le 0\). Since \(E\) is bounded below, the net must reach a stable state (a local minimum of energy) in finite steps. Stored patterns are the minima.

3.5 Storage capacity

\[ P_{max} \approx 0.15\,n \qquad \text{(Hopfield's empirical estimate)}, \qquad P_{max} \approx \frac{n}{2\log_2 n} \;\;(\text{for near-perfect recall}) \]

e.g. a 100-unit net can reliably store about 15 patterns. Storing more causes spurious states (stable states that are not stored patterns) and recall errors.

3.6 Continuous Hopfield net

Units have continuous outputs \(v_i \in (0,1)\) obtained from an internal state \(u_i\) through a sigmoid; it can be built from resistors, capacitors and amplifiers and is used for optimisation (e.g. the Travelling Salesman Problem, Hopfield & Tank, 1985).

\[ v_i = g(u_i) = \frac{1}{2}\bigl[1 + \tanh(\lambda\,u_i)\bigr], \qquad \frac{du_i}{dt} = -\frac{u_i}{\tau} + \sum_{j} w_{ij}\,v_j + \theta_i \] \[ E = -\frac{1}{2}\sum_{i}\sum_{j \ne i} w_{ij}\,v_i\,v_j - \sum_i \theta_i\,v_i + \frac{1}{\tau}\sum_i \int_{0}^{v_i} g^{-1}(v)\,dv \]
Terms
  • \(u_i\) — internal activity (like membrane potential); \(v_i\) — output; \(\lambda\) — gain; \(\tau\) — time constant; \(\theta_i\) — external bias current. \(dE/dt \le 0\), so the continuous net also settles in an energy minimum.
Applications: pattern completion, noise removal in images, optimisation (TSP, scheduling), content-addressable memory.

4. Bidirectional Associative Memory (BAM) ↑ Unit II topics

Developed by Bart Kosko (1988). BAM is a two-layer, hetero-associative, recurrent network. It stores pattern pairs \((\mathbf{s}(p), \mathbf{t}(p))\) and can recall in both directions: given \(\mathbf{x}\) it recalls \(\mathbf{y}\), and given \(\mathbf{y}\) it recalls \(\mathbf{x}\). Signals "resonate" back and forth between the two layers until both are stable.

4.1 Architecture

  • X-layer with \(n\) units and Y-layer with \(m\) units; every X unit connected to every Y unit.
  • Single weight matrix \(W\) (\(n \times m\)); signals from X to Y use \(W\), from Y to X use \(W^{T}\).
  • No connections within a layer.

4.2 Weight determination

Bipolar: \( W = \sum_{p=1}^{P} \mathbf{s}^{T}(p)\,\mathbf{t}(p) \), i.e. \( w_{ij} = \sum_p s_i(p)\,t_j(p) \)
Binary: \( w_{ij} = \sum_p \bigl[2s_i(p) - 1\bigr]\bigl[2t_j(p) - 1\bigr] \)

4.3 Activation functions

\[ \text{Y-layer: } y_{in,j} = \sum_{i} x_i\,w_{ij},\quad y_j = \begin{cases}1, & y_{in,j} \gt 0\\ y_j\ (\text{previous}), & y_{in,j} = 0\\ -1, & y_{in,j} \lt 0\end{cases} \] \[ \text{X-layer: } x_{in,i} = \sum_{j} w_{ij}\,y_j,\quad x_i = \begin{cases}1, & x_{in,i} \gt 0\\ x_i\ (\text{previous}), & x_{in,i} = 0\\ -1, & x_{in,i} \lt 0\end{cases} \]

4.4 Testing (recall) algorithm

  1. Initialise weights with the Hebb/outer-product rule.
  2. For each test input, do Steps 2–6.
  3. Present input \(\mathbf{x}\) to the X-layer (and/or \(\mathbf{y}\) to the Y-layer).
  4. While activations are not converged, do Steps 4–6.
  5. Update Y-layer: \(y_{in,j} = \sum_i x_i w_{ij}\); \(y_j = f(y_{in,j})\); send \(\mathbf{y}\) to X-layer.
  6. Update X-layer: \(x_{in,i} = \sum_j w_{ij} y_j\); \(x_i = f(x_{in,i})\); send \(\mathbf{x}\) to Y-layer.
  7. Test for convergence: stop if \(\mathbf{x}\) and \(\mathbf{y}\) no longer change.

4.5 Energy function & capacity

\[ E(\mathbf{x}, \mathbf{y}) = -\,\mathbf{x}\,W\,\mathbf{y}^{T} = -\sum_{i=1}^{n}\sum_{j=1}^{m} x_i\,w_{ij}\,y_j \]

Every update decreases (or keeps) \(E\), so BAM is always stable (Kosko's theorem). Storage capacity is roughly \(P_{max} \approx \min(n, m)\) pairs.

5. Feed Forward Networks ↑ Unit II topics

In feedforward networks, information flows only from input towards output — there are no feedback loops, so the output is computed in a single forward pass (no iteration to a stable state). Multilayer feedforward networks with non-linear hidden units are universal approximators: with enough hidden units they can approximate any continuous function to any accuracy.

6. Back Propagation Network (BPN) ↑ Unit II topics

A BPN is a multilayer feedforward network trained with the back-propagation of errors algorithm (generalised delta rule) — Rumelhart, Hinton & Williams (1986). It is supervised. Training has three stages: (1) feedforward of the input pattern, (2) back-propagation of the associated error, and (3) adjustment of the weights.

6.1 Architecture

Notation (each term explained)
  • \(\mathbf{x} = (x_1, \dots, x_i, \dots, x_n)\) — input training vector; \(\mathbf{t} = (t_1, \dots, t_k, \dots, t_m)\) — target output vector.
  • \(X_i\) — input unit \(i\); \(Z_j\) — hidden unit \(j\) (\(j = 1..p\)); \(Y_k\) — output unit \(k\).
  • \(v_{ij}\) — weight from input \(X_i\) to hidden \(Z_j\); \(v_{0j}\) — bias on hidden \(Z_j\).
  • \(w_{jk}\) — weight from hidden \(Z_j\) to output \(Y_k\); \(w_{0k}\) — bias on output \(Y_k\).
  • \(z_{in,j},\ z_j\) — net input and output of hidden unit \(j\); \(y_{in,k},\ y_k\) — net input and output of output unit \(k\).
  • \(\delta_k\) — error information term (local gradient) for output unit \(k\); \(\delta_j\) — error term for hidden unit \(j\).
  • \(\alpha\) — learning rate; \(\mu\) — momentum factor.

6.2 Training algorithm

  1. Initialise all weights \(v_{ij}, v_{0j}, w_{jk}, w_{0k}\) to small random values (e.g. in \([-0.5, 0.5]\)). Set \(\alpha\).
  2. While the stopping condition is false, do Steps 2–9.
  3. For each training pair \((\mathbf{x}, \mathbf{t})\), do Steps 3–8.
  4. [Feedforward] Each input unit \(X_i\) receives \(x_i\) and broadcasts it to all hidden units.
  5. Each hidden unit \(Z_j\) computes \[ z_{in,j} = v_{0j} + \sum_{i=1}^{n} x_i\,v_{ij}, \qquad z_j = f(z_{in,j}) \] and sends \(z_j\) to all output units.
  6. Each output unit \(Y_k\) computes \[ y_{in,k} = w_{0k} + \sum_{j=1}^{p} z_j\,w_{jk}, \qquad y_k = f(y_{in,k}) \]
  7. [Back-propagation of error] Each output unit computes its error term and weight corrections: \[ \delta_k = (t_k - y_k)\,f'(y_{in,k}), \qquad \Delta w_{jk} = \alpha\,\delta_k\,z_j, \qquad \Delta w_{0k} = \alpha\,\delta_k \] and sends \(\delta_k\) back to the hidden layer.
  8. Each hidden unit sums its delta inputs and computes its error term: \[ \delta_{in,j} = \sum_{k=1}^{m} \delta_k\,w_{jk}, \qquad \delta_j = \delta_{in,j}\,f'(z_{in,j}), \qquad \Delta v_{ij} = \alpha\,\delta_j\,x_i, \qquad \Delta v_{0j} = \alpha\,\delta_j \]
  9. [Weight update] \[ w_{jk}(\text{new}) = w_{jk}(\text{old}) + \Delta w_{jk}, \qquad v_{ij}(\text{new}) = v_{ij}(\text{old}) + \Delta v_{ij} \] (and likewise for the biases).
  10. Test stopping condition (e.g. total error \(E \lt\) tolerance, or maximum epochs).

With binary sigmoid: \(f'(y_{in,k}) = y_k(1 - y_k)\), \(f'(z_{in,j}) = z_j(1 - z_j)\). With bipolar sigmoid: \(f'(y_{in,k}) = \tfrac12(1 + y_k)(1 - y_k)\).

6.3 Derivation of the weight-update rules

Error for one pattern: \( E = \dfrac{1}{2}\sum_{k=1}^{m}(t_k - y_k)^2 \). Gradient descent: \(\Delta w = -\alpha\,\partial E / \partial w\).

Output weights (chain rule \(E \to y_k \to y_{in,k} \to w_{jk}\)): \[ \frac{\partial E}{\partial w_{jk}} = \frac{\partial E}{\partial y_k}\cdot\frac{\partial y_k}{\partial y_{in,k}}\cdot\frac{\partial y_{in,k}}{\partial w_{jk}} = -(t_k - y_k)\cdot f'(y_{in,k})\cdot z_j = -\delta_k\,z_j \;\Rightarrow\; \Delta w_{jk} = \alpha\,\delta_k\,z_j \] Hidden weights (\(v_{ij}\) affects every output through \(z_j\)): \[ \frac{\partial E}{\partial v_{ij}} = \sum_{k}\frac{\partial E}{\partial y_k}\frac{\partial y_k}{\partial y_{in,k}}\frac{\partial y_{in,k}}{\partial z_j}\cdot\frac{\partial z_j}{\partial z_{in,j}}\cdot\frac{\partial z_{in,j}}{\partial v_{ij}} = -\Bigl[\sum_k \delta_k\,w_{jk}\Bigr] f'(z_{in,j})\,x_i = -\delta_j\,x_i \;\Rightarrow\; \Delta v_{ij} = \alpha\,\delta_j\,x_i \]

The error at the output is thus "propagated back" through the same weights \(w_{jk}\) to give each hidden unit its share of blame — the name back-propagation.

6.4 Momentum

\[ \Delta w_{jk}(t+1) = \alpha\,\delta_k\,z_j + \mu\,\Delta w_{jk}(t), \qquad \Delta v_{ij}(t+1) = \alpha\,\delta_j\,x_i + \mu\,\Delta v_{ij}(t), \qquad 0 \le \mu \lt 1 \ (\text{typically } 0.9) \]

Momentum smooths the weight trajectory, speeds up learning on flat regions and helps escape shallow local minima.

6.5 Learning factors of BPN

  • Initial weights: small random values; too large saturates sigmoids (derivative ≈ 0). Nguyen–Widrow initialisation: \(\beta = 0.7\,p^{1/n}\); \(v_{ij} = \dfrac{\beta\,v_{ij}(\text{old})}{\lVert \mathbf{v}_j(\text{old}) \rVert}\); biases \(v_{0j} \in [-\beta, \beta]\).
  • Learning rate \(\alpha\): large → fast but may oscillate; small → slow. Typical \(10^{-3}\) to \(10\), commonly 0.1–0.5.
  • Momentum \(\mu\): as above.
  • Number of hidden units: too few → underfitting; too many → overfitting and poor generalisation.
  • Number of training patterns: rule of thumb \(P \approx W/e\), where \(W\) = number of weights, \(e\) = allowed fraction of classification error (e.g. \(e = 0.1\) → \(P = 10W\)).
  • Generalisation / stopping: use a validation set; stop training when validation error starts increasing (early stopping).

6.6 Merits and demerits

Merits
  • Solves non-linearly separable problems (XOR).
  • Universal function approximator.
  • Simple, systematic, widely applicable.
  • Good generalisation when trained properly.
Demerits
  • Slow convergence.
  • Can get stuck in local minima.
  • Choice of architecture/parameters is trial and error.
  • Network paralysis when sigmoids saturate.

7. Radial Basis Function Network (RBFN) ↑ Unit II topics

Introduced by Broomhead & Lowe (1988). An RBFN is a three-layer feedforward network whose hidden units use radial basis functions — functions whose output depends only on the distance of the input from a centre. It is based on Cover's theorem: a pattern-classification problem cast non-linearly into a high-dimensional space is more likely to be linearly separable than in a low-dimensional space.

7.1 Architecture

  • Input layer — passes the input vector \(\mathbf{x}\) (no weights between input and hidden layer — the "weights" are the centres).
  • Hidden layer — each unit \(j\) has a centre \(\mathbf{c}_j\) and width (spread) \(\sigma_j\); it outputs \(\varphi_j(\mathbf{x})\), large when \(\mathbf{x}\) is near \(\mathbf{c}_j\), small when far away (a local "receptive field").
  • Output layer — linear combination of hidden outputs.
\[ \varphi_j(\mathbf{x}) = \exp\!\left(-\frac{\lVert \mathbf{x} - \mathbf{c}_j \rVert^{2}}{2\sigma_j^{2}}\right), \qquad \lVert \mathbf{x} - \mathbf{c}_j \rVert^{2} = \sum_{i=1}^{n}(x_i - c_{ji})^2 \] \[ y_k = w_{0k} + \sum_{j=1}^{h} w_{jk}\,\varphi_j(\mathbf{x}) \]
Terms
  • \(\mathbf{c}_j\) — centre of hidden unit \(j\) (a point in input space).
  • \(\sigma_j\) — width/spread; controls how quickly \(\varphi_j\) falls off with distance.
  • \(\lVert\cdot\rVert\) — Euclidean norm (distance).
  • \(h\) — number of hidden (RBF) units; \(w_{jk}\) — output weights; \(w_{0k}\) — output bias.

Other radial basis functions (with \(r = \lVert\mathbf{x} - \mathbf{c}\rVert\)): multiquadric \(\varphi(r) = \sqrt{r^2 + c^2}\); inverse multiquadric \(\varphi(r) = 1/\sqrt{r^2 + c^2}\); thin-plate spline \(\varphi(r) = r^2\ln r\). The Gaussian is the most common.

7.2 Training algorithm (two stages)

  1. Choose centres \(\mathbf{c}_j\): (a) randomly select \(h\) training samples, or (b) use K-means clustering on the training inputs (unsupervised).
  2. Choose widths: a common heuristic is \( \sigma = \dfrac{d_{max}}{\sqrt{2h}} \), where \(d_{max}\) is the maximum distance between the chosen centres (or use the average distance to nearest neighbouring centres).
  3. For each training input, compute the hidden outputs \(\varphi_j(\mathbf{x})\).
  4. Find output weights (supervised, linear problem): either
    (a) LMS/delta rule: \( w_{jk}(\text{new}) = w_{jk}(\text{old}) + \alpha\,(t_k - y_k)\,\varphi_j(\mathbf{x}) \), or
    (b) Pseudo-inverse (direct least squares): \( \mathbf{w} = \Phi^{+}\mathbf{t} = (\Phi^{T}\Phi)^{-1}\Phi^{T}\mathbf{t} \), where \(\Phi\) is the \(P \times (h+1)\) matrix of hidden outputs (plus a column of 1's for bias).
  5. Repeat Step 4 (for LMS) until the error is small.

Because only the output layer is trained by supervised learning (and it is linear), RBFN trains much faster than BPN.

8. Self-Organising Feature Maps ↑ Unit II topics

Self-organising networks learn without a teacher. They are based on competitive learning: output neurons compete to be activated, and only the winner (and, in SOM, its neighbours) learns — "winner-takes-all".

  • Competition: for an input \(\mathbf{x}\), each output unit computes a discriminant (usually Euclidean distance between \(\mathbf{x}\) and its weight vector); the unit with the smallest distance wins.
  • Cooperation: the winner defines a topological neighbourhood of excited units (in SOM).
  • Adaptation: the winner (and neighbours) move their weight vectors towards the input.

Feature map / topology preservation: the output units are arranged in a 1-D line or 2-D grid, and after training, inputs that are similar in input space activate units that are close together on the grid. This mimics the topographic maps in the brain (e.g. the somatosensory and visual cortex). The two models in this unit are the unsupervised Kohonen SOM and its supervised counterpart LVQ.

\[ \text{Euclidean distance for unit } j:\quad D(j) = \sum_{i=1}^{n}\bigl(x_i - w_{ij}\bigr)^2, \qquad \text{winner } J = \arg\min_{j} D(j) \]

9. Kohonen Self-Organising Map (SOM) ↑ Unit II topics

Developed by Teuvo Kohonen (1982). A SOM maps high-dimensional input vectors onto a low-dimensional (usually 2-D) grid of cluster units while preserving topology. It is used for clustering, vector quantisation, visualisation and data compression.

9.1 Architecture

  • Input layer: \(n\) units; output (Kohonen/cluster) layer: \(m\) units arranged linearly, in a rectangular grid, or a hexagonal grid.
  • Each cluster unit \(Y_j\) has a weight vector \(\mathbf{w}_j = (w_{1j}, \dots, w_{nj})\) — an "exemplar" or prototype of its cluster.
  • Neighbourhood radius \(R\): all units within distance \(R\) of the winner on the grid are also updated. For a rectangular grid, R = 1 has 8 neighbours, R = 2 has 24; for a hexagonal grid, R = 1 has 6 neighbours. R is reduced as training proceeds.

9.2 Training algorithm

  1. Initialise weights \(w_{ij}\) (random), set topological neighbourhood radius \(R\) and learning rate \(\alpha\).
  2. While the stopping condition is false, do Steps 2–8.
  3. For each input vector \(\mathbf{x}\), do Steps 3–5.
  4. For each cluster unit \(j\), compute \( D(j) = \sum_{i=1}^{n}(x_i - w_{ij})^2 \).
  5. Find index \(J\) such that \(D(J)\) is minimum (the winner).
  6. For all units \(j\) within the neighbourhood of \(J\), and for all \(i\): \[ w_{ij}(\text{new}) = w_{ij}(\text{old}) + \alpha\bigl[x_i - w_{ij}(\text{old})\bigr] = (1 - \alpha)\,w_{ij}(\text{old}) + \alpha\,x_i \]
  7. Update learning rate (it decreases slowly with time), e.g. \( \alpha(t+1) = 0.5\,\alpha(t) \).
  8. Reduce the radius \(R\) of the topological neighbourhood at specified times.
  9. Test stopping condition (e.g. \(\alpha\) becomes very small, or weights stop changing).
Modern (Gaussian) neighbourhood form: \[ \mathbf{w}_j(t+1) = \mathbf{w}_j(t) + \alpha(t)\,h_{J,j}(t)\,\bigl[\mathbf{x} - \mathbf{w}_j(t)\bigr], \qquad h_{J,j}(t) = \exp\!\left(-\frac{d_{J,j}^{2}}{2\sigma^{2}(t)}\right) \] where \(d_{J,j}\) is the grid distance between winner \(J\) and unit \(j\), and \(\sigma(t)\) shrinks with time.
Meaning of the update The weight vector moves a fraction \(\alpha\) of the way from its current position towards the input. With \(\alpha = 0.6\), the new weight is 40 % old weight + 60 % input.

10. Learning Vector Quantization (LVQ) ↑ Unit II topics

LVQ (Kohonen, 1986–1990) is a supervised version of competitive learning. Its architecture is the same as a SOM without topological neighbourhood: each output unit represents a known class. The weight vectors are called reference (codebook) vectors. After training, an input is assigned to the class of the output unit whose reference vector is closest.

Notation
  • \(\mathbf{x}\) — training vector; \(T\) — correct class of \(\mathbf{x}\).
  • \(\mathbf{w}_j\) — reference vector of output unit \(j\); \(C_j\) — class represented by unit \(j\).
  • \(\lVert\mathbf{x} - \mathbf{w}_j\rVert\) — Euclidean distance.

10.1 Training algorithm

  1. Initialise reference vectors (e.g. take the first \(m\) training vectors, one per class, or random vectors with class labels). Initialise \(\alpha\).
  2. While the stopping condition is false, do Steps 2–6.
  3. For each training input \(\mathbf{x}\) (with class \(T\)), do Steps 3–4.
  4. Find \(J\) such that \(\lVert\mathbf{x} - \mathbf{w}_J\rVert\) is minimum.
  5. Update \(\mathbf{w}_J\): \[ \text{if } T = C_J:\quad \mathbf{w}_J(\text{new}) = \mathbf{w}_J(\text{old}) + \alpha\bigl[\mathbf{x} - \mathbf{w}_J(\text{old})\bigr] \quad(\text{move towards } \mathbf{x}) \] \[ \text{if } T \ne C_J:\quad \mathbf{w}_J(\text{new}) = \mathbf{w}_J(\text{old}) - \alpha\bigl[\mathbf{x} - \mathbf{w}_J(\text{old})\bigr] \quad(\text{move away from } \mathbf{x}) \]
  6. Reduce the learning rate \(\alpha\).
  7. Test stopping condition (fixed number of epochs or \(\alpha\) sufficiently small).

10.2 Variants

  • LVQ2: updates the two nearest reference vectors (winner \(\mathbf{w}_J\) of wrong class, runner-up \(\mathbf{w}_{K}\) of correct class) if \(\mathbf{x}\) falls in a "window" around the mid-plane: \(\dfrac{d_c}{d_r} \gt 1 - \varepsilon\) and \(\dfrac{d_r}{d_c} \lt 1 + \varepsilon\) (typically \(\varepsilon \approx 0.35\)). Then \(\mathbf{w}_c \leftarrow \mathbf{w}_c + \alpha(\mathbf{x} - \mathbf{w}_c)\), \(\mathbf{w}_r \leftarrow \mathbf{w}_r - \alpha(\mathbf{x} - \mathbf{w}_r)\).
  • LVQ2.1: considers the two closest vectors regardless of which is the winner; window condition \(\min\!\left(\dfrac{d_1}{d_2}, \dfrac{d_2}{d_1}\right) \gt 1 - \varepsilon\) and \(\max\!\left(\dfrac{d_1}{d_2}, \dfrac{d_2}{d_1}\right) \lt 1 + \varepsilon\).
  • LVQ3: also updates when both closest vectors are of the correct class, using a smaller rate \(\beta = m\alpha\) (\(0.1 \lt m \lt 0.5\)) to keep reference vectors stable.
